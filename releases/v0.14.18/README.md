# Release 0.14.18

Questa directory contiene la fotografia documentale immutabile della release applicativa 0.14.18.

## Contenuto

- `OPERATOR_GUIDE.md`: uso ordinario, manutenzione, invii controllati, emergenze e consegna operativa;
- `DEPLOYMENT.md`: provisioning, configurazione esterna, rollout e rollback;
- `REFERENCE.md`: contratti dati, fogli, messaggi, registro, diagnostica e configurazione GitHub;
- `VALIDATION.md`: evidenze e limiti di validazione registrati per la release.

## Regola di immutabilità

Questi documenti descrivono esclusivamente la release 0.14.18. Le release successive devono creare una nuova directory `releases/vX.Y.Z/` invece di riscrivere questa fotografia.

Lo stato corrente controllato dal repository è in `../../CURRENT_STATE.json`; le regole per modificare il progetto sono in `../../AGENTS.md`.
